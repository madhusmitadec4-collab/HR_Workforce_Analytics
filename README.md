# HR Workforce Analytics

## Project Overview

An end-to-end HR Workforce Analytics project built using Power BI, SQL, Python, Excel, and Power Query.

The project analyzes workforce structure, employee attrition, recruitment effectiveness, attendance, training, and employee performance to support HR decision-making.

## Business Objectives

- Analyze workforce headcount and employee status
- Identify departments with high attrition
- Evaluate recruitment sources and joining rates
- Analyze employee attendance
- Track training completion
- Analyze employee performance
- Build interactive HR dashboards
- Provide actionable HR insights
